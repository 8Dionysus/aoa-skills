# Local Eval Port

This port is intentionally forming. The previous trigger and live-dispatch
harness targeted the retired 57-bundle ontology and was removed from the
active tree. Git history remains the provenance record; its reports are not
current skill truth.

## Manual-first admission

Evaluation starts outside the repository with a controlled, manually reviewed
comparison:

1. no skill;
2. current skill;
3. candidate skill or composition;
4. direct provision versus retrieval;
5. flat selection versus task-local DAG when composition is relevant.

Record the repository revision, model, host, visible skill catalog, tools,
inputs, acceptance criteria, artifacts, token use, elapsed time, and every
material failure. Manual review decides what happened. A validator may be
created only after several trials reveal a stable invariant whose future drift
would otherwise be hard to detect.

## Admission boundary

Repository-local eval material must be reusable, public-safe, owner-scoped,
and independent of one session. Raw prompts, transcripts, temporary runners,
one-off reports, model verdicts, and session-memory extracts remain
session-local. Central scoring and proof adoption route to aoa-evals.

There are currently no admitted durable suites. This is an honest state, not a
coverage failure.
