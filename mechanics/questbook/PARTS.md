# Questbook Parts

This file is the active map of functioning Questbook parts in `aoa-skills`.

## Part Map

| Part | Local function | Stronger owner route |
|---|---|---|
| [Source Index Boundary](parts/source-index-boundary/README.md) | keep root `QUESTBOOK.md`, `quests/`, schemas, and generated projections in their correct authority order | source quest objects and owner repos own obligation truth |
