# Questbook Integration

A durable obligation belongs in Questbook only after current work proves it
cannot be resolved or represented in capability or skill source, a decision,
or an external owner handoff.

Task-local DAGs, raw trials, live goals, and temporary follow-up remain
session-only. Quest closure needs evidence from the named owner; generated read
models never close or promote anything.

The builder derives the catalog and dispatch views from admitted YAML sources.
Those generated read models are consumers, not a hidden second source of truth.
