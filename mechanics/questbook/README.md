# Questbook

This package owns the `aoa-skills` side of the cross-project Questbook
mechanic: durable skill obligations, session-harvest integration posture, and
quest dispatch projection boundaries.

Root `QUESTBOOK.md` stays the public tracked obligation surface. This package
keeps the movement around it legible without turning Questbook into a second
roadmap or private scratchpad.

## Mechanic card

Status: `landed-local-integration-start`.

### Trigger

Use this package when a deferred skill obligation, quest-dispatch projection,
or session-harvest aftermath needs to stay visible without becoming a skill
bundle, playbook, proof verdict, memory object, or hidden task queue.

### Local owns

This package owns questbook integration posture, session-harvest family
relationship, allowed quest-harvest verdict surface, source/index boundary
around root `QUESTBOOK.md` and lane-first `quests/`, and
generated quest catalog/dispatch projection routes.

### Stronger owner split

`Agents-of-Abyss` owns center Questbook law. Root `QUESTBOOK.md`
and lane-first `quests/` own repo-local public obligations. `aoa-playbooks`
owns recurring choreography.
`aoa-evals` owns proof obligations. `aoa-memo` owns retained lessons. Owner
repositories own local acceptance and closure. Generated quest views reflect
source obligations without authoring them.

### Inputs

- durable skill obligation
- session-harvest aftermath
- quest-harvest verdict pressure
- generated quest catalog or dispatch drift
- quest schema or source object route

### Outputs

- questbook integration route
- source/index boundary note
- session-harvest posture
- generated projection route
- no closure, proof, playbook, memory, routing, or owner truth by itself

### Must not claim

- second roadmap
- private scratchpad
- owner acceptance
- closure proof
- proof verdict
- playbook choreography
- memory canon
- routing authority
- generated quest views as source truth
- automatic skill or playbook promotion

accept work for another owner.
