# Supporting Mechanics

| Package | Independent owner-local role |
| --- | --- |
| `agon/` | preserve explicitly requested workflow candidates without promoting them into skill truth |
| `questbook/` | preserve durable repository obligations and derive compact dispatch read models |
| `release-support/` | define portable export, pack identity, staging, installation, verification, and release handoff |

All semantic discovery and composition now lives in `capabilities/`. Session
harvest/recovery lives in its callable families. Historical audit, bridge,
checkpoint, growth, recurrence, RPG, experience, and antifragility mechanics
were retired from the active tree because they no longer owned an independent
contract.
