# Release Support Provenance

This bridge records the source-to-active move for release-support surfaces.

## Moved active docs

Active release-support docs moved from `docs/` to
`mechanics/release-support/docs/`.

Key groups:

- portable export and config snippets
- component refresh and local adapter contracts
- install profiles and release procedure
- runtime seam, guardrails, trust, context, and compaction
- deterministic resources and UI metadata

## Historical wave docs

Earlier wave and phase notes moved to `mechanics/release-support/legacy/waves/`.
They preserve history and are not first-route contracts.

## Stop-line

Release-support surfaces package and validate. They do not replace authored
skills or own runtime behavior.
