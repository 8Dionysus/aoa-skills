# Audit Parts

| Part | Owns | Does not own |
|---|---|---|
| Audit contract | repo-local review and risk checklist | proof verdicts |
| Evaluation path | how to read skill behavior evidence | runtime selection |
| Public surface read | how to read generated status/governance outputs | promotion authority |
| Trigger quality | trigger and description activation checks | routing policy |
| Conformance lane | skills-ref and standards-adjacent checks | external standard authority |

Use the active docs under `docs/` for each part.
