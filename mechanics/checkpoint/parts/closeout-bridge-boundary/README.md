# Closeout Bridge Boundary

## Use When

Use this part when a reviewed session artifact exists and checkpoint hints need
to narrow attention for one explicit closeout bridge without replacing donor
harvest, progression lift, or quest harvest evidence review.

## Do Not Use When

Do not use this part for active mid-session collection, hidden execution inside
`aoa closeout run`, final verdicts from checkpoint notes alone, stats refresh,
or bridge-skill implementation work.

## Route Check

- Is there a reviewed session artifact?
- Are checkpoint notes treated as shortlist hints?
- Is the fixed order visible: donor harvest, progression lift, quest harvest?
- Does every stage reread reviewed evidence?
- Is stats refresh outside the bridge?

## Active Outputs

- explicit closeout bridge request
- reviewed evidence requirements
- fixed core-skill order
- rejected stale or contaminated hint posture
- downstream stats-refresh hold

Route execution to the canonical
`skills/core/session-growth/aoa-checkpoint-closeout-bridge/SKILL.md`. The bridge skill coordinates
the explicit closeout chain; this mechanics part only names the boundary.
