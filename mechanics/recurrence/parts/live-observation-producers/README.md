# Live Observation Producers

## Use When

Use this part when description-trigger eval cases, trigger docs, generated
trigger manifests, live skill receipts, or session-harvest notes produce skill
omission or activation-gap signals.

## Do Not Use When

Do not use this part to invoke a skill automatically, rewrite a trigger
boundary, change a bundle, close a quest, or treat generated evidence as review
authority.

## Route Check

- Which producer supplied the observation?
- Is the signal a missing trigger, unused-skill opportunity, collision
  avoidance case, or explicit-only restraint?
- Is there reviewable evidence beyond one isolated observation?
- Does the next route belong to trigger evals, applicability maps, candidate
  harvest, or another owner?

## Active Outputs

- observation producer note
- review pressure cue
- trigger-eval or applicability follow-through cue
- no activation, proof, or owner acceptance claim
