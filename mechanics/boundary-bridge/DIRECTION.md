# Boundary Bridge Direction

Boundary bridge keeps crossings explicit.

The active route is:

```text
skill-facing boundary pressure
  -> bridge contract or overlay route
  -> generated feed or owner handoff
  -> stronger owner if truth must move
```

## Current contour

- Layer position, bridge spec, support-dir bridge, two-stage selection, overlay
  contract, MCP wiring, and OpenAI metadata live under package-local `docs/`.
- Live overlay family docs live under `overlays/`.
- Generated tiny-router and export outputs remain derived surfaces.

## Boundary

Bridge surfaces connect layers. They do not transfer ownership.
