# RPG Direction

This package starts with the smallest honest `aoa-skills` RPG slice: ability
reader surfaces and loadout posture.

The active route is:

```text
canonical skill bundle
  -> generated/evaluation/profile evidence
  -> ability or loadout reader hint
  -> owner route if choreography, proof, runtime state, or progression truth is needed
```

## Current contour

- Skill meaning remains under `skills/*/SKILL.md`.
- Ability cards remain generated reader surfaces.
- Loadout means reviewable subset posture, not equipped runtime state.
- Pack profiles and trust surfaces do the honest subset work first.
- Playbook choreography stays out of this package.

## Boundaries

- Growth-cycle may provide progression-adjacent session evidence.
- Questbook owns durable quest-shaped obligations.
- Playbooks own scenario builds, rotations, and campaign method.
- Runtime owners own stateful inventory or UI delivery.

## Current hold

Do not move ability schemas, generated ability examples, pack profiles, or
progression artifacts in this slice.
