# Growth-Cycle Examples

Public-safe examples for session-growth artifact and receipt families.

These examples preserve reviewed lineage, packet, receipt, progression, repair,
and automation-follow-through shapes. They are evidence shapes, not generated
authority and not skill activation state.

## Naming

Example families use semantic suffixes rather than wave labels:

- `reviewed-donor-harvest`: first reviewed donor-harvest lineage family
- `derived-visibility-handoff`: derived stats and handoff repair family
- `kernel-maturity`: reviewed session-growth kernel maturity family
