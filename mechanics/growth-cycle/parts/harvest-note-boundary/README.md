# Harvest Note Boundary

## Use When

Use this part when committed session-harvest notes need to remain public-safe
evidence below skill review, owner-layer promotion, memory canon, proof, or
playbook authority.

## Do Not Use When

Do not use this part to move or rewrite all session-harvest notes, to promote a
candidate, to replace questbook obligations, or to treat a session note as a
final verdict.

## Route Check

- Is the note bounded and public-safe?
- Is it clearly below promotion authority?
- Does it avoid becoming skill review or status-promotion evidence by itself?
- Does it name the next owner route when one exists?

## Active Outputs

- harvest-note boundary
- evidence route to `mechanics/growth-cycle/session-harvests/`
- candidate-harvest template route
- next-owner hint

## Next Route

as provenance rather than moving authority into the note.
