# Growth-Cycle

This package owns the `aoa-skills` side of the cross-project Growth Cycle
mechanic: adaptive skill orchestration, closeout-versus-harvest separation, and
session-growth kernel maturity guidance.

It keeps task execution, closeout, checkpoint carry, harvest, progression,
quest triage, and owner followthrough distinct without turning any one stage
into the whole system.

## Mechanic card

Status: `landed-local-orchestration-start`.

### Trigger

Use this package when a session or repo change needs to decide which skills
apply now, which belong to closeout, which belong to harvest, and how reviewed
session-growth kernel examples carry evidence after `candidate_ref` already
exists.

### Local owns

This package owns adaptive skill orchestration guidance, applicability-map
route, closeout-versus-harvest stop-lines, session-growth kernel maturity
guidance, and the boundary around session-harvest notes as evidence rather than
promotion verdicts.

### Stronger owner split

`Agents-of-Abyss` owns center Growth Cycle law and stage order. `aoa-sdk` owns
hooks, checkpoint ledgers, and closeout context. `aoa-agents` owns self-agent
posture. `aoa-evals` owns proof and regression. `aoa-memo` owns memory
writeback. `aoa-playbooks` owns recurring choreography. `aoa-stats` owns
derived visibility. `aoa-routing` owns navigation hints. `Dionysus` owns
reviewed snapshots and seed lineage when promotion is explicit.

### Inputs

- multi-skill task execution pressure
- closeout ambiguity
- checkpoint note or harvest handoff pressure
- session-growth kernel examples
- project-core kernel config and receipt publisher contract
- session-harvest notes as evidence

### Outputs

- applicability map route
- closeout-versus-harvest decision guidance
- explicit session-harvest family handoff
- reviewed packet and receipt example boundary
- no proof, memory, runtime, owner acceptance, hidden automation, or final
  progress claim by itself

### Must not claim

- executable skill truth
- proof verdict
- memory canon
- runtime activation
- owner acceptance
- hidden scheduler
- autonomous self-repair
- universal progression score
- quest promotion authority without reviewed evidence
- method-growth final object truth

do not replace the skills that execute donor harvest, progression lift,
diagnosis, repair, route forks, automation scan, or quest harvest.
