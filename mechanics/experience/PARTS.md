# Experience Parts

| Part | Owns | Does not own |
|---|---|---|
| Adoption governance | local owner consent and adoption packet posture | cross-owner consent |
| Policy and stay | hold and stay-order skill contracts | hidden veto authority |
| Installation | validate, migrate, smoke, replay, rollback skill surface | release approval |
| Receipts | receipt-generation contract | final proof |
| Office/service | task boundary and handoff skill contracts | runtime office authority |
| Runtime governance | bounded governance-runtime skills | runtime law |

Use `docs/` for the active contract text.
