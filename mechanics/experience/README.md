# Experience

This package owns the `aoa-skills` side of Experience mechanics: bounded
skill-layer contracts for consent, office/service operation, receipts,
installation, rollback, and governance holds.

## Mechanic card

Status: `landed-local-route`.

### Trigger

Use this package when work touches Experience-shaped skill surfaces around
installation, release trains, office tasks, service handoff, receipt generation,
policy holds, stay orders, or local adoption consent.

### Local owns

`aoa-skills` owns owner-local workflow contracts and stop-lines for these
skill surfaces.

### Stronger owner split

`Agents-of-Abyss` owns Experience law and release posture. `Tree-of-Sophia`
owns no-runtime-write and canon boundaries. Runtime owners own activation.
Downstream owners own local consent.

### Inputs

- Experience route signal
- local owner consent or lack of consent
- office/service handoff pressure
- receipt or installation workflow pressure
- rollback, stay, or policy hold request

### Outputs

- bounded skill contract
- owner-local hold, handoff, receipt, rollback, or adoption route
- no release approval, runtime write, assistant self-authority, or ToS meaning

### Must not claim

- release approval
- runtime activation authority
- assistant self-recharter or self-promotion
- direct Tree-of-Sophia write authority
- owner consent for another repository
