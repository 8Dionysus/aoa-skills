# Agon Candidate Intake

Agon contributes two requested-only candidate families:

- `workflow-candidate-bridge/`: fourteen lawful-move workflow requests bound
  to the `Agents-of-Abyss` owner registry;
- `epistemic-candidate-boundary/`: nine epistemic capability requests with
  explicit forbidden effects.

Both families are candidate input to the semantic capability ecosystem. They
do not presume that the final realization is a skill: it may remain a
capability, bind to a playbook/workflow/tool, be rejected, or later qualify as
a callable bundle.

The generated `agon_*_capability_candidates.min.json` files are deterministic
requested-only projections. Builders and validators live with each source.
No candidate grants live arena, proof, scar, rank, trust, memory, KAG, ToS, or
automatic promotion authority.
