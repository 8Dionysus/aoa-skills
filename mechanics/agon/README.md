# Agon

This package owns the `aoa-skills` side of the cross-project Agon mechanic:
requested-only bounded workflow candidates behind lawful moves.

It keeps Agon skill-binding pressure, epistemic workflow candidates, and
observation-only recurrence routes visible without turning them into skill
canon, arena law, proof verdicts, scars, or routing sovereignty.

## Mechanic card

Status: `mapped-with-local-evidence requested-only bridge`.

### Trigger

Use this package when Agon lawful-move work produces skill-layer pressure:
candidate workflow bindings, epistemic workflow requests, recurrence
observations, or validation routes that must remain requested-only until normal
skill review accepts them.

### Local owns

This package owns the skill-layer candidate bridge, generated candidate input
boundaries, recurrence observation posture, validation route, and stop-lines
for Agon-facing workflow candidates in `aoa-skills`.

### Stronger owner split

`Agents-of-Abyss` owns center Agon law and lawful-move vocabulary.
`aoa-techniques` owns reusable practice candidates behind Agon moves.
`aoa-evals` owns proof strength.
`aoa-routing` owns routing policy.
`aoa-agents` owns role and runtime actor contracts.
`Tree-of-Sophia` owns ToS canon-facing meaning.
Downstream repositories own local adoption and runtime use.

### Inputs

- center-side Agon owner-binding requests
- `config/agon_skill_binding_candidates.seed.json`
- `config/agon_epistemic_skill_candidates.seed.json`
- generated Agon candidate companions
- recurrence manifests that observe this package
- reviewed practice or skill evidence that still needs normal bundle review

### Outputs

- requested-only skill-binding candidate surfaces
- epistemic skill candidate surfaces
- observation-only recurrence pressure
- validation routes for Agon candidate surfaces
- no promoted skill bundle without normal `skills/` review

### Must not claim

- lawful move vocabulary
- arena session law
- proof verdicts
- durable scars
- routing sovereignty
- runtime activation
- ToS canon
- source-owner acceptance
- automatic skill promotion

that made a move lawful and do not activate a skill by recurrence alone.
