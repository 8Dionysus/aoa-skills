# Lawful-Move Capability Candidates

This part preserves fourteen `requested_not_landed` workflow candidates from
the current `Agents-of-Abyss` Agon move binding. Each candidate names its owner
binding, intent, requirements, and forbidden claims.

The candidates require a reviewed procedural basis or owner workflow, not a
technique package. They enter capability classification first. A separate
callability and held-out outcome review is required before any `SKILL.md` can
be created.
