# Agon Roadmap

## Current baseline

Agon skill-layer mechanics now have a package-local active route.

The first landing distilled existing flat Agon docs into functional
active parts. It did not promote any candidate into a skill bundle and did not
change generated candidate meaning.

## Next honest passes

- Keep package-local legacy snapshots narrow and source-preserving; do not let
  the archive become a second active route.
- Plan a separate generated/config schema migration if historical wave fields
  need to be retired rather than carried as lineage metadata.
- Consider a package-local artifact topology note if Agon-specific schemas,
  examples, scripts, tests, or generated companions stop fitting root technical
  districts.
- Review whether any requested-only candidate has enough technique traceability
  and skill evidence to enter normal `skills/` review.
- Keep recurrence manifests observation-only when their paths change.

## Stop lines

- Do not convert every lawful move into a skill.
- Do not treat recurrence pressure as activation authority.
- Do not let Agon package language define center Agon law.
