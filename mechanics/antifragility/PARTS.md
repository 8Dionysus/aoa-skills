# Antifragility Parts

This file maps current antifragility-shaped risk posture to active
`aoa-skills` parts. It is not the AoA center antifragility part map and not a
replacement for skill canon.

## Part Map

| Part | Local function | Stronger owner route |
|---|---|---|
| [Fallback Authoring Posture](parts/fallback-authoring-posture/README.md) | keep degraded-mode, fallback, safe-stop, receipt, and adaptation writeback cues visible for future skill authoring | skill bundles own final wording; owner repos own local degraded behavior |
| [Via Negativa Pruning](parts/via-negativa-pruning/README.md) | decide when a skill should stay intact, merge, move, suppress, quarantine, deprecate, or be removed from canon | owner routes and review evidence own actual removal or replacement |
| [Collision Stress Program](parts/collision-stress-program/README.md) | keep collision stress inside trigger eval, description eval, and tiny-router validation surfaces | `aoa-routing` owns routing behavior; `aoa-evals` owns proof doctrine |

## Active Part Contract

Every part keeps this active-route shape:

- `## Use When`
- `## Do Not Use When`
- `## Route Check`
- `## Active Outputs`
- `## Next Route`
