# Antifragility Direction

This package starts with the smallest honest `aoa-skills` antifragility slice:
fallback authoring posture, via negativa pruning, and collision stress routing.

The active route is:

```text
skill-layer stress or pruning pressure
  -> antifragility route check
  -> fallback, pruning, or collision-stress part
  -> owner route if proof, runtime behavior, deletion, release, or cleanup is needed
```

## Current contour

- Skill meaning remains under `skills/*/SKILL.md`.
- Fallback posture is an authoring cue, not a new schema mandate.
- Via negativa asks whether a skill stays necessary, bounded, and
  non-redundant.
- Collision stress stays inside trigger eval, description eval, and
  tiny-router validation surfaces.
- Generated and runtime readouts remain evidence, not authority.

## Boundaries

- Audit reads evaluation evidence and public status.
- Release-support owns portable export, install, release-manifest, and runtime
  seam packaging pressure.
- Experience owns operator-facing adoption, installation, and consent posture
  when the work is not just skill-layer stress routing.
- Owner repositories own local deletion, rollback, cleanup, and runtime
  execution.

## Current hold

Do not move `docs/ROLLBACK_DRILL_SKILL.md` in this slice. It belongs to the
v1.0 installation and release posture and needs a release-support or
experience route before any antifragility split would be honest.
