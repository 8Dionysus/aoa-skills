# Skill-effectiveness family reviews

This folder stores the current public reviewed lifecycle disposition for the
whole AoA skill family.

## Current record

`aoa-family-current.json` covers every current `SKILL.md` exactly once and
chooses one `improve`, `split`, `merge`, `promote`, `retain`, or `retire`
disposition per skill.

Git history preserves earlier cycles. The current record moves when source
membership, path, scope, status, disposition, or action state changes.

## Evidence boundary

The record keeps these episode stages separate:

- prompt visibility
- target selection or legitimate nonactivation
- full load/read
- followed procedure or legitimate deflection
- verification
- bounded outcome

Mentions and co-occurrence remain non-authoritative signals. Public
live-dispatch receipts are reviewed candidate evidence only. Raw session
content, private Codex traces, host paths, and `.aoa` refs do not belong in the
record.

## Authority boundary

The family review does not change skill status, prove effectiveness, accept a
project overlay, or authorize runtime behavior. Per-skill promotion records,
source bundles, `aoa-evals`, and runtime owners keep those responsibilities.

The contract and lifecycle grammar live in
`mechanics/method-growth/docs/SKILL_EFFECTIVENESS_FAMILY_REVIEW.md`. The JSON
Schema lives beside the other Method-Growth schemas, and the focused validator
keeps the current record source-exact and public-safe.
