# Lifecycle Reviews

This directory intentionally contains no inherited promotion records from the
retired 57-skill catalog. Current visibility and evidence posture are authored
in capability family sources.

A future review belongs here only when it compactly records held-out manual
comparisons, owner-qualified evidence, attribution limits, and a concrete
improve/split/merge/promote/demote/supersede/remove decision. Raw session
material remains with the session; shared proof remains with `aoa-evals`.
