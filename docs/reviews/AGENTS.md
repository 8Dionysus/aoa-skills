# AGENTS.md

## Applies to

This card applies to `docs/reviews/`.

## Role

This district may hold compact admitted lifecycle reviews for current
capability families or callable bundles.

## Read before editing

Inspect affected capability and bundle sources, the manual trial protocol, and
any cited proof-owner result. Use the README only for review-index changes.

## Boundaries

Do not store raw traces, task-local plans, old catalog promotions, or a green
validator transcript. A review may recommend lifecycle movement but cannot
silently promote config or source. Superseded reviews leave the active surface.

## Validation

Manually verify cited cases and owner refs, then run only structural checks
affected by an admitted lifecycle change.

## Closeout

Report evidence class, held-out scope, attribution limits, lifecycle decision,
source change, and unresolved runtime/model coverage.
