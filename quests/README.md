`quests/<lane>/<state>/AOA-SK-Q-*.yaml`. There are currently none.

`quests/agon/captured/*.md` contains two external requested-only candidates and
is governed by Agon, not by the repo-local Questbook lifecycle.

must not duplicate the active goal, capability source, skill procedure,
decision record, session evidence, or another owner's backlog.
