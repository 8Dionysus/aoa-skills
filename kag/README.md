# aoa-skills Local KAG Provider

This directory is a derived provider packet for the semantic capability tree
and its typed graph. `aoa-kag` may retrieve and compose these records, while
authored meaning remains in `capabilities/` and callable procedures remain in
`skills/`.

| Surface | Role |
| --- | --- |
| `manifest.json` | provider sources, return routes, consumers, validation |
| `nodes/` | capability graph and canonical source-home handles |
| `edges/` | explicit return from derived graph to authored semantics |
| `indexes/provider_readiness_index.json` | compact provider record inventory |
| `indexes/index_family.manifest.json` | content-addressed portable index-family boundary |
| `indexes/shards/` | bounded JSONL shards for repository knowledge records |
| `projections/` | MCP-facing source-return view |
| `receipts/` | validation route and freshness handle |

The primary derived source is `generated/capability_graph.json`. Its semantic
owner is `capabilities/README.md`; `skills/README.md` is the return route for
nine shared callable source bundles, seven advertised and two deferred. The portable KAG family is regenerated by
`aoa-kag:scripts/generate_repo_local_kag_index.py` and never hand-maintained.
Exact legacy JSON index views remain deterministic on-demand assemblies rather
than tracked monoliths.

Git stores portable records and indexes. Runtime retrieval materializations,
embeddings, caches, and serving state do not belong here.
