# AGENTS.md

## Applies to

This card applies to `.agents/`.

## Role

`aoa-skills/.agents/skills/` intentionally remains absent. Shared bundles are
selected once through the OS user profile; an explicit external consumer may
request a temporary flat portable assembly without making this repository a
second prompt-visible source.

## Read before editing

Read root `AGENTS.md`, `skills/AGENTS.md`, `generated/AGENTS.md`, the portable
layer release doc, and the export builder/validator before changing portable
consumer behavior.

## Boundaries

Do not add shared skill bundles here. Do not hand-edit an external portable
assembly as authority, add host-only policy to core procedure source, or infer
native prompt visibility from package generation.

## Validation

Change authored source or config, stage the portable package in a temporary or
explicit external consumer root, validate its bytes, then use a clean host
context for prompt-visible behavior when that claim matters.

## Closeout

Report source bundle, external assembly route, byte identity, cleanup, host
visibility checked or skipped, and deferred behavior evidence.
