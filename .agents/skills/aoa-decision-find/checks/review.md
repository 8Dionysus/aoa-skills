# Review Checklist

## Purpose

Use this checklist when reviewing work that claims to use `aoa-decision-find`.

## When it applies

- the task asks which prior decision, rationale, owner surface, or source surface applies
- graph or generated-index lookup can narrow the search
- final claims still need source-note verification
- missing or stale matches may need a create or correct follow-up

## Review checklist

- [ ] Graph, packet, or generated-index lookup was used as the first search aid.
- [ ] Final rationale claims were verified against source decision notes.
- [ ] Matches include repo, decision ID, path, status, and relevance reason.
- [ ] Weak or missing matches are reported instead of inflated.
- [ ] Create or correct follow-up is named when lookup is insufficient.

## Not a fit

- New source decision records belong to `aoa-decision-create`.
- Repairs to existing records belong to `aoa-decision-correct`.
