# Example

## Scenario

No existing eval fits a repeated failure, and the repo has a local eval port.

## Why this skill fits

- selection has already found no adequate existing surface
- the next artifact is local pressure, not central proof
- rejected alternatives and evidence refs must be preserved

## Expected inputs

- target repo and `evals/PORT.yaml`
- failure or behavior needing evaluation
- evidence refs and touched paths
- rejected existing evals or validators

## Expected outputs

- one `evals/intake/*.eval_need.json` packet
- proof-limit statement
- validation command or skipped-check note
- next review or design route

## Boundary notes

- local intake is pressure, not proof acceptance
- central `aoa-evals` review is required for proof promotion
- broad or duplicate packets should be avoided

## Verification notes

- verify no existing eval fit
- verify packet path and owner route
- verify central proof surfaces were not changed
